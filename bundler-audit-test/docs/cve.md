# CVE

CVE significa `Common Vulnerabilities and Exposures` (Vulnerabilidades e Exposições Comuns).

É um padrão internacional usado para identificar e catalogar vulnerabilidades de segurança conhecidas em softwares.

Cada vulnerabilidade recebe um identificador único, no formato:

    CVE-ANO-NÚMERO


Exemplo: CVE-2024-12345

### Função do CVE:

Criar uma referência única e universal para que empresas, pesquisadores e desenvolvedores possam falar da mesma falha de segurança sem confusão.

Usado em bancos de dados de segurança, relatórios e ferramentas como bundle audit.

👉 Ou seja: quando o bundle audit mostra que uma gem tem um CVE, **significa que essa versão da dependência já está documentada como vulnerável oficialmente**.
